Επίπεδο 2: Μεταβλητές στη C

Τι είναι μια μεταβλητή - int - float - double - char

5 ενότητες - 30 ερωτήσεις - 3 ασκήσεις κώδικα

Η πρόοδός σου

0 / 30

Έχεις ολοκληρώσει 0 από τις 30 ερωτήσεις.

Πρακτικές ασκήσεις: 0 / 3

Συγχαρητήρια! Ολοκλήρωσες το Επίπεδο 2!

Τελική επανάληψη – Γράψε κώδικα C

Λύσε τις τρεις ασκήσεις γράφοντας κώδικα. Ο έλεγχος εξετάζει τη δομή του κώδικα, χωρίς πραγματική μεταγλώττιση ή εκτέλεση.

Ολοκληρωμένες ασκήσεις: 0 / 3

Άσκηση 1: Οι πρώτες μου μεταβλητές

Δήλωσε τις μεταβλητές int age = 20;, float height = 1.75f;, double pi = 3.1415926535; και char initial = 'M';. Έπειτα εμφάνισε τις τιμές τους χρησιμοποιώντας printf().

Άσκηση 2: Προσωπικά στοιχεία

Δήλωσε τις μεταβλητές int age = 18;, float height = 1.70f; και char initial = 'A';. Εμφάνισε την ηλικία, το ύψος και το αρχικό του ονόματος με τους σωστούς προσδιοριστές %d, %f και %c.

Άσκηση 3: Διαδραστικό πρόγραμμα

Δήλωσε int age;, float height; και char initial;. Διάβασε τις τρεις τιμές με scanf() και εμφάνισέ τες με printf().
