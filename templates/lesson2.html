📦 Επίπεδο 2: Μεταβλητές στη C

Σωστές απαντήσεις: 0 / 15

📖 Σύνοψη

Οι μεταβλητές είναι από τις πιο βασικές έννοιες στον προγραμματισμό. Μια μεταβλητή είναι ένας χώρος στη μνήμη του υπολογιστή όπου μπορούμε να αποθηκεύσουμε μια τιμή και να τη χρησιμοποιήσουμε αργότερα στο πρόγραμμά μας. Στη C, πριν χρησιμοποιήσουμε μια μεταβλητή, πρέπει να δηλώσουμε τον τύπο των δεδομένων που θα αποθηκεύει. Για παράδειγμα, ο τύπος int χρησιμοποιείται για ακέραιους αριθμούς, όπως 5, 20 ή -3. Ο τύπος float χρησιμοποιείται για αριθμούς με δεκαδικό μέρος, όπως 3.14 ή 7.5. Ο τύπος double χρησιμοποιείται επίσης για δεκαδικούς αριθμούς, αλλά με μεγαλύτερη ακρίβεια. Ο τύπος char χρησιμοποιείται για έναν μόνο χαρακτήρα, όπως 'A' ή 'x'. Μπορούμε να δηλώσουμε μια μεταβλητή γράφοντας πρώτα τον τύπο της, μετά το όνομά της και στο τέλος ελληνικό ερωτηματικό. Για παράδειγμα, int age;. Αν θέλουμε να της δώσουμε τιμή αμέσως, μπορούμε να γράψουμε int age = 20;. Αυτό ονομάζεται αρχικοποίηση. Η τιμή μιας μεταβλητής μπορεί να αλλάξει κατά την εκτέλεση του προγράμματος. Για παράδειγμα, αν έχουμε int score = 10;, αργότερα μπορούμε να γράψουμε score = 15;. Για να εμφανίσουμε την τιμή μιας μεταβλητής με την printf(), χρησιμοποιούμε ειδικά σύμβολα μορφοποίησης. Το %d χρησιμοποιείται για int, το %f για δεκαδικούς αριθμούς και το %c για χαρακτήρες. Η C ξεχωρίζει τα κεφαλαία από τα πεζά γράμματα, επομένως οι μεταβλητές age και Age θεωρούνται διαφορετικές. Επίσης, ένα όνομα μεταβλητής δεν πρέπει να ξεκινά με αριθμό.

💻 Παραδείγματα

int age = 20;
float temperature = 23.5;
double price = 19.99;
char grade = 'A';

printf("%d", age);
printf("%f", temperature);
printf("%c", grade);

Μπορούμε επίσης να αλλάξουμε την τιμή μιας μεταβλητής: 

int score = 10;

score = 20;

printf("%d", score);

Το αποτέλεσμα θα είναι: 

20
