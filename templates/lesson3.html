Τελική Επανάληψη – Γράψε κώδικα C

Γράψε τις λύσεις σου στους editors. Ο έλεγχος γίνεται χωρίς εκτέλεση κώδικα.

Ολοκληρωμένες ασκήσεις: 0 / 3

Άσκηση 1: Σύγκριση δύο αριθμών

Δήλωσε int a = 10; και int b = 5;. Δήλωσε μια μεταβλητή int result που θα αποθηκεύει το αποτέλεσμα της σύγκρισης a > b. Εμφάνισε το result με printf() και %d.

Άσκηση 2: Λογικοί τελεστές

Δήλωσε int age = 20;. Δημιούργησε μια μεταβλητή int valid που θα ελέγχει αν η ηλικία είναι τουλάχιστον 18 και το πολύ 65, χρησιμοποιώντας &&. Εμφάνισε το αποτέλεσμα με printf().

Άσκηση 3: Αύξηση και σύνθετη ανάθεση

Δήλωσε int score = 10;. Αύξησε το score κατά 1 με score++;. Στη συνέχεια πρόσθεσε 5 με score += 5;. Εμφάνισε την τελική τιμή με printf().
