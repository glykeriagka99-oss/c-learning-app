Τελική επανάληψη – Γράψε κώδικα C

Λύσε τις τρεις ασκήσεις γράφοντας κώδικα C. Ο έλεγχος εξετάζει τη δομή του κώδικα, χωρίς πραγματική μεταγλώττιση ή εκτέλεση.

Ολοκληρωμένες ασκήσεις: 0 / 3

Άσκηση 1: Δημιουργία και εμφάνιση πίνακα

Δημιούργησε έναν πίνακα int numbers[5] με τιμές 10, 20, 30, 40, 50. Χρησιμοποίησε for και printf για να εμφανίσεις όλα τα στοιχεία του.

Άσκηση 2: Εισαγωγή στοιχείων σε πίνακα

Δημιούργησε έναν πίνακα int numbers[5]. Χρησιμοποίησε έναν βρόχο for και τη scanf για να διαβάσεις πέντε ακέραιους από τον χρήστη.

Άσκηση 3: Άθροισμα στοιχείων πίνακα

Δημιούργησε έναν πίνακα int numbers[5] με τιμές 1, 2, 3, 4, 5. Δήλωσε μια μεταβλητή sum = 0. Χρησιμοποίησε for για να προσθέσεις όλα τα στοιχεία και εμφάνισε το αποτέλεσμα με printf.
