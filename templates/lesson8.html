Επίπεδο 8: Συναρτήσεις (Functions)

Μάθε να οργανώνεις τον κώδικά σου σε συναρτήσεις.

5 ενότητες - 30 ερωτήσεις - 3 ασκήσεις κώδικα

Η πρόοδός σου

0 / 30

Έχεις ολοκληρώσει 0 από τις 30 ερωτήσεις.

Πρακτικές ασκήσεις: 0 / 3

🎉 Συγχαρητήρια!

Ολοκλήρωσες το Επίπεδο 8 και έφτασες στο τέλος της εκπαιδευτικής διαδρομής!

Έχεις πλέον γνωρίσει τις βασικές έννοιες προγραμματισμού στη γλώσσα C.

Τελική επανάληψη – Γράψε κώδικα C

Ολοκλήρωσε τις τρεις ασκήσεις συναρτήσεων. Ο έλεγχος γίνεται με JavaScript και αναγνωρίζει βασικά στοιχεία του κώδικα, χωρίς πραγματική μεταγλώττιση ή εκτέλεση C.

Ολοκληρωμένες ασκήσεις: 0 / 3

Άσκηση 1: Η πρώτη σου συνάρτηση

Δημιούργησε μία συνάρτηση void hello(void) που εμφανίζει Hello C! με printf. Στη συνέχεια, κάλεσέ τη μέσα στη main.

Άσκηση 2: Συνάρτηση με παραμέτρους

Δημιούργησε μία συνάρτηση int add(int a, int b), η οποία επιστρέφει το άθροισμα των δύο αριθμών με return a + b;. Μέσα στη main κάλεσε add(5, 3) και εμφάνισε το αποτέλεσμα με printf.

Άσκηση 3: Συνάρτηση και πίνακας

Δημιούργησε τη συνάρτηση int sumArray(int a[], int n). Χρησιμοποίησε έναν βρόχο for για να προσθέσεις τα στοιχεία του πίνακα και επέστρεψε το άθροισμα. Μέσα στη main δημιούργησε τον πίνακα {1, 2, 3, 4, 5}, κάλεσε sumArray(numbers, 5) και εμφάνισε το αποτέλεσμα.
