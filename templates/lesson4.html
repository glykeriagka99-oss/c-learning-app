Τελική Επανάληψη – Γράψε κώδικα C

Λύσε τις τρεις ασκήσεις στον editor. Ο έλεγχος εξετάζει συγκεκριμένα στοιχεία του κώδικα χωρίς να τον εκτελεί.

Ολοκληρωμένες ασκήσεις: 0 / 3

Άσκηση 1: Έλεγχος ενηλικίωσης

Γράψε πρόγραμμα που δηλώνει int age = 20;. Με if / else έλεγξε αν age >= 18. Αν ισχύει, εμφάνισε Adult, αλλιώς Minor.

Άσκηση 2: Θετικός, αρνητικός ή μηδέν

Δήλωσε int number = -5;. Χρησιμοποίησε if, else if και else. Αν ο αριθμός είναι μεγαλύτερος από 0, εμφάνισε Positive. Αν είναι μικρότερος από 0, εμφάνισε Negative. Διαφορετικά εμφάνισε Zero.

Άσκηση 3: Επιλογή με switch

Δήλωσε int choice = 2;. Χρησιμοποίησε switch (choice). Στο case 1 εμφάνισε One, στο case 2 εμφάνισε Two και στο default εμφάνισε Unknown. Βάλε break; μετά από κάθε case.
