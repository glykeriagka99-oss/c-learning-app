📖 Σύνοψη

Η C είναι μια γλώσσα προγραμματισμού γενικού σκοπού και αποτελεί μία από τις σημαντικότερες γλώσσες για την κατανόηση των βασικών αρχών του προγραμματισμού. Ένα απλό πρόγραμμα C ξεκινά συνήθως με την οδηγία #include <stdio.h>, η οποία μας επιτρέπει να χρησιμοποιούμε λειτουργίες εισόδου και εξόδου όπως τις printf() και scanf(). Η εκτέλεση ενός προγράμματος ξεκινά από τη συνάρτηση main(). Με την printf() μπορούμε να εμφανίζουμε πληροφορίες στην οθόνη, ενώ με τη scanf() μπορούμε να λαμβάνουμε δεδομένα που πληκτρολογεί ο χρήστης. Για την αποθήκευση δεδομένων χρησιμοποιούμε μεταβλητές. Ο τύπος int χρησιμοποιείται για ακέραιους αριθμούς, ο float για αριθμούς με δεκαδικό μέρος και ο char για έναν χαρακτήρα. Για παράδειγμα, int age = 20; δημιουργεί μία μεταβλητή με όνομα age και τιμή 20. Στη C οι περισσότερες απλές εντολές ολοκληρώνονται με ελληνικό ερωτηματικό ;. Μπορούμε επίσης να πραγματοποιούμε αριθμητικές πράξεις χρησιμοποιώντας τους τελεστές +, -, *, / και %. Όταν το πρόγραμμα πρέπει να πάρει μια απόφαση, χρησιμοποιούμε την if και προαιρετικά την else. Για επαναλαμβανόμενες ενέργειες μπορούμε να χρησιμοποιήσουμε βρόχους όπως for και while. Τα σχόλια μιας γραμμής γράφονται με // και βοηθούν τον προγραμματιστή να εξηγεί τον κώδικα χωρίς να εκτελούνται από τον υπολογιστή. Τέλος, η εντολή return 0; στο τέλος της main() χρησιμοποιείται συνήθως για να δηλώσει ότι το πρόγραμμα ολοκληρώθηκε επιτυχώς.

💻 Παράδειγμα

#include <stdio.h>

int main() {

    int age = 20;

    printf("Hello!");
    printf("Age: %d", age);

    return 0;
}

Μην ανησυχείς αν δεν θυμάσαι ακόμα όλα τα παραπάνω. Στόχος αυτού του επιπέδου είναι να εξοικειωθείς με τις βασικές έννοιες. Θα τις συναντήσουμε ξανά στα επόμενα επίπεδα.
